# Music

Each profile plays the tracks in its own sub-folder (`music_dir` in `profiles/<name>.json`):

| Folder | Used by |
|---|---|
| `study/` | study, coding |
| `sleep/` | sleep |
| `trading/` | trading-music |
| `trivia/` | trivia-247 |

Drop `.mp3`, `.m4a`, `.ogg`, `.wav`, `.flac` or `.opus` files in. They play shuffled, and the file name
(without the extension, `_` and `-` shown as spaces) appears on stream as "now playing".

**Only use music you have the rights to stream on YouTube**: the YouTube Audio Library, a royalty-free
library whose licence covers live streams, or music you made or generated on a plan that grants
commercial use. Copyrighted songs get live streams muted, taken down or struck.

Files in these folders are not committed to git.
