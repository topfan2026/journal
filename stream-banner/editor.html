Hide areas

A frosted box that hides part of your screen (account balance, order panel…). Position and size are in % of the screen. The overlay sits on top of your chart, so it can't blur what's underneath: it covers it. For a true blur, see the README.

How saving works
  1. Click Save & go live once and choose banner-config.js in this folder (replace it).
  2. From then on, with Live ticked, every change goes on stream about a second after you stop typing. No more saving. Next time you open the editor, the first change asks once to allow editing the file.
  3. If your browser can't save directly (use Chrome or Edge), it downloads banner-config.js: move it into the stream-banner folder, replacing the old one.
  4. OBS checks the file every second. You don't need to touch OBS.
  5. Images (logo, promo pictures, QR code) must be copied into this folder first; then type the file name, e.g. logo.png.
